# 서울 의료·돌봄 시뮬레이터

초고령사회 서울에서 의료·돌봄 정책을 **실행하지 않을 때**와 **실행할 때**를 같은 조건으로 나란히 돌려 비교하는 확률 시뮬레이터입니다.

## 실행

```bash
python serve.py
```

브라우저에서 http://localhost:8765 를 엽니다. 파일을 더블클릭해서 열면 데이터를 불러올 수 없으니 반드시 서버로 열어야 합니다.

## 화면 구성

- **두 개의 지도**: 왼쪽은 정책 없음, 오른쪽은 정책 적용입니다. 시간은 1시간 단위로 흐르고 낮과 밤이 바뀝니다.
  - 점 하나는 어르신 N명(기본 100명)이고, 색은 건강상태를 나타냅니다.
  - 낮에는 외래 진료를 오가고, 방문진료팀(청록색 십자)이 집을 방문합니다. 입원은 응급 이송(빨간 점)으로 표시됩니다.
  - 밤에는 집에 불이 켜집니다.
  - 구 색깔은 선택한 지표(돌봄 미충족 비율 등)를 나타냅니다.
- **정책 탭**: 방문진료팀, 재가돌봄 확충, 독거노인 안부·연계, 시설 확충, 퇴원 연계, 대상 자치구, 시작일을 조절합니다.
- **파라미터 탭**: 모든 확률과 오즈비를 직접 입력할 수 있습니다. `가정` 표시는 아직 근거 데이터로 교체하지 않은 값입니다.
- **데이터 탭**: 자치구별 CSV를 올리면 그 데이터로 바로 다시 실행됩니다.
- **몬테카를로 검증**: 같은 조건을 반복 실행해 정책 효과의 평균과 95% 신뢰구간을 계산합니다.

## 모델 (통계적 근거)

| 구성 요소 | 방법 |
|---|---|
| 가상 인구 | 구별 통계(65세 이상, 75세 이상, 독거, 수급)에 맞춘 개인 단위 표본 생성 |
| 건강상태 | 건강 → 허약 → 돌봄필요 → 입원/시설 → 사망. 1일 단위 **이산시간 마르코프 연쇄** |
| 개인 위험 | 기준확률에 **로지스틱 모형**으로 오즈비를 적용: `p' = expit(logit(p) + Σ ln(OR)·x)` (나이, 독거, 고립, 수급, 서비스 미충족) |
| 확률 변환 | 연간 확률을 일간 확률로 변환: `1-(1-p)^(1/365)` (위험률 일정 가정) |
| 서비스 배분 | 구별 용량(시설 수 × 1곳당 처리량) 안에서 매일 배분. 기존 이용자 유지 → 독거 우선(정책) → 무작위 |
| 피드백 | 돌봄 미충족이나 의료 공백이 생기면 입원·시설입소·사망 위험이 커지고, 이것이 다시 수요를 바꿈 |
| 시나리오 비교 | **공통난수법(CRN)**: 두 시나리오가 같은 난수를 공유해서 차이가 정책 효과만 반영함 |
| 불확실성 | **몬테카를로** 반복 실행 → 대응표본 차이의 평균과 t분포 기반 95% 신뢰구간 |

## 폴더 구조

```
index.html          화면
css/style.css
js/stats.js         난수, 확률 변환, 로지스틱, Erlang C, 신뢰구간
js/params.js        파라미터·정책 레버 정의 (값, 단위, 근거 메모)
js/engine.js        시뮬레이션 엔진 (DOM 없음, 워커와 공용)
js/render.js        지도 렌더링 (낮/밤, 이동 연출)
js/chart.js         시계열 차트
js/worker.js        몬테카를로 반복 실행
js/main.js          화면 연결
data/districts.csv  자치구 입력 데이터 (현재는 임시값)
data/seoul_gu.geojson  자치구 경계 (southkorea/seoul-maps, KOSTAT 2013)
js/csv.js           CSV 읽기/쓰기 (브라우저·Node 공용)
batch/run.js        서버용 배치 실행기 (Node.js, 멀티코어 병렬)
batch/scenarios.example.json  배치 시나리오 설정 예시
DATA_SOURCES.md     받아야 할 데이터 목록
SERVER.md           학교 서버(SSH)에서 실행하는 방법
```

## 현재 상태와 한계

- `data/districts.csv`는 **임시값**입니다. 팀 분석 문서의 1만 명당 비율과 대략적인 인구 추정으로 만들었으므로 결과를 인용하면 안 됩니다.
- 파라미터는 대부분 **가정값**입니다. `DATA_SOURCES.md`의 B 항목으로 보정해야 합니다.
- 다른 구의 병원을 이용하는 경우는 `cross_border` 하나의 비율로 단순화했습니다.
